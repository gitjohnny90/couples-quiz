  <action>
For each of the 5 files, apply:

**Part A — mountedRef guard:**
1. Ensure `useRef` is imported from React
2. Add `const mountedRef = useRef(true)` near top of component
3. Add cleanup effect: `useEffect(() => { mountedRef.current = true; return () => { mountedRef.current = false } }, [])`
4. For pages with useCallback async fetches (PredictPartnerPage has one), add `if (!mountedRef.current) return` after await, before setState
5. For pages with simple async functions inside useEffect (VisionTab, StudyTogetherPage, LoveNoteHuntPage, MoviesPage), guard setState calls after await with the mountedRef check. If the async function is defined inside the useEffect (not useCallback), you can use either `let mounted = true` local pattern OR the shared mountedRef — prefer mountedRef for consistency since these pages also have channels that fire callbacks

**Part B — unique channel name:**
Channel name prefixes to preserve:
- VisionTab: `vision-${sessionId}`
- StudyTogetherPage: `study-${sessionId}`
- LoveNoteHuntPage: `love-notes-${sessionId}-r${round}` — NOTE: this includes `round` which may change. Use useRef but compute it with current round value. If round changes, the channel cleanup + re-subscribe will create a new channel anyway, so the random suffix just needs to be unique per mount.
- MoviesPage: `shared-items-movies-${sessionId}`
- PredictPartnerPage: `predict-${sessionId}`

For each: add `const channelId = useRef(\`{prefix}-${Math.random().toString(36).slice(2, 8)}\`)` and use `channelId.current` in the `.channel()` call. For LoveNoteHuntPage where round is dynamic, the channelId can be computed inside the useEffect since it already re-runs when round changes — just use a local `const name = \`love-notes-${sessionId}-r${round}-${Math.random().toString(36).slice(2, 8)}\`` directly in the effect (no ref needed since the effect re-creates on round change).

**Important:** Do not change any other logic, styling, or behavior.
