Three changes to QuizPage.jsx:

1. **Add sessionId sync (QUIZ-04 root cause fix):**
   - Destructure `setSessionId` from `useContext(SessionContext)` (currently only destructures `playerName, playerId`)
   - Add useEffect after the existing destructuring block:
     ```javascript
     useEffect(() => {
       if (sessionId) setSessionId(sessionId)
     }, [sessionId])
     ```
   - This is the exact pattern from PredictPartnerPage.jsx line 39-41

2. **Add isMounted ref for handleNext (CLN-01 for QuizPage):**
   - Add `useRef` to the React import (already has useContext, useState, useEffect, useCallback)
   - Add `const mountedRef = useRef(true)` near the top of the component
   - Add useEffect for cleanup: `useEffect(() => { mountedRef.current = true; return () => { mountedRef.current = false } }, [])`
   - In handleNext catch block, wrap the two setState calls with `if (mountedRef.current)`:
     ```javascript
     catch (err) {
       console.error("oops, couldn't save:", err)
       if (mountedRef.current) {
         setError("couldn't save your answers — try again")
         setSubmitted(false)
       }
     }
     ```
   - Also guard `setPartnerAnswered(true)` in fetchPartnerResponse with `if (mountedRef.current)`

3. **Add unique channel name (CLN-02 for QuizPage):**
   - Add a channelId ref: `const channelId = useRef(\`quiz-${sessionId}-${packId}-${Math.random().toString(36).slice(2, 8)}\`)`
   - In the realtime useEffect, replace the hardcoded channel name `\`quiz-${sessionId}-${packId}\`` with `channelId.current`
   - Do NOT put channelId in the useEffect dependency array (useRef values are stable)
