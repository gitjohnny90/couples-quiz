While the JSX interpolation should work, unify both to use a single computed variable to guarantee they always match. In each file:

1. Add a computed `shareUrl` variable near the top of the component (after `sessionId` is available):

   const shareUrl = `${window.location.origin}/join/${sessionId}`

In ResultsPage.jsx, the display is around line 159. In DrawResultsPage.jsx, the display is around line 148.

This ensures a single source of truth for the URL — no possibility of display/copy mismatch.
