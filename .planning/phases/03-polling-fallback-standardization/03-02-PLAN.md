1. Replace the plain `fetchResponses` function (lines 44-53) with a `useCallback`-wrapped version:
```javascript
const fetchResponses = useCallback(async () => {
  const { data, error } = await supabase
    .from('deep_dive_responses').select('*')
    .eq('session_id', sessionId).eq('deck_id', deckId)
  if (!error && data) {
    setResponses(data)
    return data
  }
  return []
}, [sessionId, deckId])
```

2. Update the initial load effect (lines 64-71) to include `fetchResponses` in deps:
```javascript
useEffect(() => {
  const init = async () => {
    const data = await fetchResponses()
    resumeFromResponses(data)
    setLoading(false)
  }
  init()
}, [fetchResponses])
```
Note: `resumeFromResponses` reads `deck` and `playerId` from closure which are stable (from params/context). This is acceptable.

3. Update the realtime subscription effect (lines 74-89) to include `fetchResponses` in deps:
```javascript
useEffect(() => {
  const channel = supabase
    .channel(`deep-dive-${sessionId}-${deckId}`)
    .on('postgres_changes', {
      event: '*',
      schema: 'public',
      table: 'deep_dive_responses',
      filter: `session_id=eq.${sessionId}`,
    }, (payload) => {
      if (payload.new && payload.new.deck_id === deckId) {
        fetchResponses()
      }
    })
    .subscribe()
  return () => { supabase.removeChannel(channel) }
}, [sessionId, deckId, fetchResponses])
```

4. Update the polling effect (lines 104-116) to include `fetchResponses` in deps and keep the phase gate:
```javascript
useEffect(() => {
  if (phase !== PHASE.WAITING || !deck) return
  const interval = setInterval(async () => {
    const data = await fetchResponses()
    const partnerDone = deck.questions.every((q) =>
      data.some((r) => r.question_id === q.id && r.player_id !== playerId)
    )
    if (partnerDone) {
      setPhase(PHASE.RESULTS)
    }
  }, 5000)
  return () => clearInterval(interval)
}, [phase, fetchResponses, deck, playerId])
```

Do NOT change the realtime event filter (already `event: '*'` — correct). Do NOT change the phase-gating logic (already correct for RT-05). Do NOT refactor `resumeFromResponses` — it is only called once on init and does not need `useCallback`.
