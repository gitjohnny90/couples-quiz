Add partner answer detection to QuizPage so users know when their partner has already submitted. This is a lightweight addition — QuizPage is submit-only, so the subscription just sets a boolean `partnerAnswered` state.

1. Add `useEffect`, `useCallback` to the existing React import at line 1.

2. Add a `partnerAnswered` state: `const [partnerAnswered, setPartnerAnswered] = useState(false)`

3. Create a `useCallback`-wrapped fetch function that checks for partner's response:
```javascript
const fetchPartnerResponse = useCallback(async () => {
  const { data } = await supabase
    .from('responses')
    .select('player_id')
    .eq('session_id', sessionId)
    .eq('pack_id', packId)
    .neq('player_id', playerId)
  if (data && data.length > 0) setPartnerAnswered(true)
}, [sessionId, packId, playerId])
```

4. Add initial load effect: `useEffect(() => { fetchPartnerResponse() }, [fetchPartnerResponse])`

5. Add realtime subscription effect (separate from initial load, event: '*'):
```javascript
useEffect(() => {
  const channel = supabase
    .channel(`quiz-${sessionId}-${packId}`)
    .on('postgres_changes', {
      event: '*',
      schema: 'public',
      table: 'responses',
      filter: `session_id=eq.${sessionId}`,
    }, (payload) => {
      if (payload.new && payload.new.pack_id === packId && payload.new.player_id !== playerId) {
        setPartnerAnswered(true)
      }
    })
    .subscribe()
  return () => { supabase.removeChannel(channel) }
}, [sessionId, packId, playerId])
```

6. Add a polling fallback effect, gated on `!partnerAnswered` (stops polling once partner is detected):
```javascript
useEffect(() => {
  if (partnerAnswered) return
  const interval = setInterval(fetchPartnerResponse, 5000)
  return () => clearInterval(interval)
}, [fetchPartnerResponse, partnerAnswered])
```

7. Add a subtle indicator in the UI. After the progress bar div (around line 120), add a conditional message when partnerAnswered is true:
```jsx
{partnerAnswered && !submitted && (
  <p style={{
    textAlign: 'center',
    fontFamily: 'var(--font-hand)',
    fontSize: '0.95rem',
    color: 'var(--accent-sage)',
    marginBottom: 8,
    fontStyle: 'italic',
  }}>
    your person already answered this one!
  </p>
)}
```

Do NOT add polling during the answering phase that could overwrite user input. The polling only checks for partner's existence, never touches the current user's answer state.
