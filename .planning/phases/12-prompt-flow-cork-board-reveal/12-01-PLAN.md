```javascript
export function isSectionCompleteForPlayer(playerAnswers, sectionId) {
  const photos = playerAnswers?.[sectionId]
  if (!Array.isArray(photos) || photos.length < 3) return false
  return photos.every(p => p !== null && p?.path)
}
```

Create `src/pages/DailyPhotoSectionPage.jsx` — the full prompt flow page. Follow the 12-UI-SPEC.md contract exactly for all visual details.

**Imports:** useState, useCallback, useEffect from react. useParams, useNavigate from react-router-dom. motion, AnimatePresence from framer-motion. useSessionSetup, useRealtimeSync, supabase, PhotoCaptureInput, photoSections, isSectionCompleteForPlayer, PageDoodles, PageGuide.

**Component structure:**

1. **Setup:** Use `useSessionSetup()` for sessionId, playerId, partnerId, partnerName, mountedRef. Get `sectionId` from `useParams()`. Find section from `photoSections.find(s => s.id === sectionId)`. If section not found, render error with link to `/daily-photos/${sessionId}`.

2. **State:** `currentPromptIndex` (0), `screen` ('loading' | 'prompting' | 'waiting').

3. **Mount effect:** Fetch the player's existing per-player row from `responses` (pack_id='daily-photo-challenge', player_id=playerId). Extract `answers[sectionId]` array. Find first null/missing-path entry index. If all 3 present, set screen='waiting'. Otherwise set currentPromptIndex to that index and screen='prompting'. Deps: [sessionId, playerId, sectionId].

4. **savePromptAnswer function:** Fresh-fetch the player's row, merge the new photo into the section array at currentPromptIndex, upsert back. This prevents overwriting other sections' data. Pattern from research Pattern 1.

5. **handlePhotoSubmit callback:** Call savePromptAnswer(path, caption). If currentPromptIndex < 2, advance index. If index was 2 (last), set screen='waiting' and call checkBothComplete().

6. **markSectionCompleteInSharedState function:** Fresh-fetch the shared row (player_id='shared'). Set `inProgressSectionId: null`, add `completedSections[sectionId]: new Date().toISOString()`, set `lastCompletedAt: new Date().toISOString()`. Upsert shared row.

7. **checkBothComplete (useCallback):** Fetch both player rows in parallel with Promise.all. Check isSectionCompleteForPlayer for both. If both true, call markSectionCompleteInSharedState(), then navigate to `/daily-photo-reveal/${sessionId}/${sectionId}`. Deps: [sessionId, sectionId, playerId, partnerId, screen].

8. **useRealtimeSync:** table='responses', sessionId, onUpdate=checkBothComplete, channelPrefix='daily-photo-section', pollingEnabled=(screen === 'waiting').

9. **Render — loading state:** Simple "loading..." text (Patrick Hand 1.25rem, var(--text-secondary), textAlign center, paddingTop 64).

10. **Render — prompting state:**
    - `.page` container with `position: relative`
    - `<PageGuide pageKey="dailyPhotoSection" />`
    - `<PageDoodles seed={12} />`
    - `<motion.div initial={{ opacity: 0, y: 15 }} animate={{ opacity: 1, y: 0 }}>`
    - **Header block:** Flex row with section emoji (28px, marginRight 10) and section title (Caveat 1.25rem weight 600). Below title: "Prompt {N} of 3" label (Patrick Hand 0.875rem, var(--text-secondary), lineHeight 1.4). Header marginBottom 16.
    - **Step indicator:** 3 dots, flex row, gap 8, justifyContent center, marginBottom 8. Each dot: 10px circle. Completed = coral bg. Active = coral bg + 2px box-shadow ring (`0 0 0 2px var(--bg-paper), 0 0 0 4px var(--accent-coral)`). Remaining = var(--border-pencil) bg, opacity 0.6.
    - **Progress bar:** div with className="progress-bar-track", marginBottom 24. Inner div with className="progress-bar-fill", width = `${((currentPromptIndex + (screen === 'waiting' ? 1 : 0)) / 3) * 100}%`. When waiting (all 3 done), fill is 100%.
    - **AnimatePresence mode="wait"** wrapping the PhotoCaptureInput with a motion.div keyed on currentPromptIndex. Exit: opacity 0, x -20. Enter: opacity 0, x 20 -> opacity 1, x 0.
    - **PhotoCaptureInput** props: prompt={section.prompts[currentPromptIndex].text}, onPhotoSubmit={handlePhotoSubmit}, sessionId, playerId, sectionId, promptIndex={currentPromptIndex}.

11. **Render — waiting state:**

    - Button: className="btn btn-secondary", label "check back", onClick triggers checkBothComplete manually
    - Add `role="status"` on the waiting container for accessibility

**Typography constraint:** Only use 0.875rem, 1rem, 1.25rem, 2rem. No fractional intermediates.

**Player colors:** player1 = coral (#E88D7A), player2 = blue (#7EB8D8) — always by player ID.
