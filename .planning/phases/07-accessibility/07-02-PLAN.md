  <name>Task 1: Add dialog semantics, focus trap, and Escape handling to PageGuide</name>
  <files>src/components/PageGuide.jsx</files>
  <action>
The PageGuide overlay (lines 92-179) currently renders as a plain `motion.div` backdrop with a `motion.div` content panel. It needs:

1. **Dialog role and aria attributes on the content panel** (~line 111 inner `motion.div`):
   - Add `role="dialog"`, `aria-modal="true"`, `aria-label={guide.title}`

2. **Escape key handling:**
   - Add a `useEffect` that listens for `keydown` on `document` when `showOverlay` is true. On `Escape`, call `dismiss()`. Clean up the listener on unmount or when overlay closes.
   ```javascript
   useEffect(() => {
     if (!showOverlay) return
     const handleKey = (e) => { if (e.key === 'Escape') dismiss() }
     document.addEventListener('keydown', handleKey)
     return () => document.removeEventListener('keydown', handleKey)
   }, [showOverlay])
   ```

3. **Focus management — move focus into dialog on open, restore on close:**
   - Add a `triggerRef` (`useRef(null)`) and attach it to the (?) `motion.button` (~line 62).
   - Add a `dialogRef` (`useRef(null)`) and attach it to the inner content `motion.div` (~line 111). Give it `tabIndex={-1}` so it can receive programmatic focus.
   - When overlay opens, focus the "got it!" button inside the dialog. Use a `useEffect` watching `showOverlay`: when true, use `setTimeout(() => gotItRef.current?.focus(), 100)` (small delay for framer-motion animation). Add a `gotItRef` on the "got it!" button (~line 160).
   - When overlay closes (dismiss function), restore focus to `triggerRef.current` after state update: `setTimeout(() => triggerRef.current?.focus(), 50)`.

4. **Focus trap — keep Tab cycling within the dialog:**
   - The dialog has exactly 2 focusable elements: the dialog content div (tabIndex -1, not in tab order) and the "got it!" button.
   - Add an `onKeyDown` handler on the dialog content div that traps Tab:
   ```javascript
   onKeyDown={(e) => {
     if (e.key === 'Tab') {
       e.preventDefault()
       gotItRef.current?.focus()
     }
   }}
   ```
   This is sufficient because with only one tabbable element (the button), Tab should always stay on it. The backdrop `onClick={dismiss}` already handles clicking outside.

5. **Prevent body scroll while dialog is open** (optional but good practice):
   - In the `useEffect` for showOverlay, add `document.body.style.overflow = 'hidden'` on open and restore on cleanup.

Keep all existing framer-motion animations and styling intact. Only add accessibility attributes and behavior.
