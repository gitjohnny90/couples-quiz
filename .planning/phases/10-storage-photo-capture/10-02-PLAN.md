Create `src/components/PhotoCaptureInput.jsx` as a default-exported React component.

**Props:**
- `prompt` (string) — the photo prompt text displayed above the capture area
- `onPhotoSubmit` (function) — callback with `(path, caption)` after successful upload
- `sessionId` (string) — current session ID
- `playerId` (string) — 'player1' or 'player2'
- `sectionId` (string) — section identifier for storage path
- `promptIndex` (number) — 0, 1, or 2 for the 3 prompts per section

**State:**
- `selectedFile` (File | null) — raw file from input
- `previewUrl` (string | null) — blob: URL from createPreviewUrl
- `caption` (string) — caption text, default ''
- `uploading` (boolean) — upload in progress
- `error` (string | null) — error message

**Imports:**
```javascript
import { useState, useRef, useEffect } from 'react'
import { supabase } from '../lib/supabase'
import { uploadPhoto, createPreviewUrl, revokePreviewUrl } from '../utils/photoUtils'
import TornPaperCaption from './TornPaperCaption'
```

**Lifecycle:**
- `useEffect` cleanup: revoke previewUrl on unmount to prevent memory leak
```javascript
useEffect(() => {
  return () => { revokePreviewUrl(previewUrl) }
}, [previewUrl])
```

**Handlers:**

`handleFileSelected(file)`:
- If file is falsy, return
- Revoke previous previewUrl if exists
- Set `selectedFile` to file
- Set `previewUrl` to `createPreviewUrl(file)`
- Clear `error`

`handleRemove()`:
- Revoke previewUrl
- Set `selectedFile` to null, `previewUrl` to null, `caption` to ''
- Reset both hidden file input refs via `.current.value = ''`

`handleSubmit()`:
- Set `uploading` to true, `error` to null
- Call `const { path, error } = await uploadPhoto(supabase, sessionId, playerId, sectionId, promptIndex, selectedFile)`
- If error: set `error` to error string, set `uploading` to false, return
- Call `onPhotoSubmit(path, caption)`
- Set `uploading` to false
